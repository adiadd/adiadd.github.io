# Timeless fonts (not committed)

The [Timeless type family](https://timeless.co/type) is licensed under the
[Timeless Free Font License v1.2](https://timeless.co/type/license). Personal and
commercial web embedding is allowed, but §6 forbids putting the font files on a
public server or in a public repository. That's why the files are gitignored.

Get the fonts through the "Get access" form on timeless.co/type, then drop these files here:

- `TimelessSerifVF.woff2` (wght 200–700)
- `TimelessSerifItalicVF.woff2` (wght 300–700)
- `TimelessSansVF.woff2` (wght 300–800)

If the files are missing, the site falls back to Georgia / system-ui.
